# Hyper Context Checklist

**Reference:** [Hyper Context Strategy](../strategies/hyper-context-strategy.md)

- [ ] Target directory has an `AGENTS.md` file.
- [ ] Target directory has a `rules.md` file.
- [ ] Target directory has a `canonical.md` file.
- [ ] Root `AGENTS.md` contains a pointer to the target directory's `AGENTS.md`.
- [ ] Localized files only contain rules scoped to that specific directory boundary (no global rules).
