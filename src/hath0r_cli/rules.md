# CLI Core Subsystem - Local Rules

> Specific rules and constraints for the CLI Core Subsystem module.

## Constraints
- **CR-CLI-TECH-DEBT-001**: Zero Hidden Tech Debt. Any self-admitted technical debt (TODOs, FIXMEs, workarounds) MUST be handed to the Issue Bot (`hath0r issue create` / `gh issue create`) and explicitly presented to the user with clickable links.
