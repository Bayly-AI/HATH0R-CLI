# Troubleshooting Procedure

**Reference:** [Troubleshooting Strategy](../strategies/troubleshooting-strategy.md) | [Troubleshooting Playbook](../playbooks/playbook-troubleshooting.md)

## Steps
1. **Intake:** Receive and review the bug report.
2. **Reproduce:** Establish a Minimal Reproducible Example (MRE).
3. **Isolate:** Execute the steps in the [Troubleshooting Runbook](../runbooks/troubleshooting-runbook.md) to isolate the bug's origin (API, EDGE, DB, UI).
4. **Fix:** Develop the fix.
5. **Verify:** Use the [Troubleshooting Checklist](../checklists/troubleshooting-checklist.md) to ensure the fix is validated in lower environments.
6. **RCA:** Conduct and document a Root Cause Analysis.
