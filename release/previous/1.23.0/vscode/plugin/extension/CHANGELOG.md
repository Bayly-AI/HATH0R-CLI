# Changelog

All notable changes to the "hath0r-vscode" extension will be documented in this file.

## [0.9.0] - 2026-10-04

### Initial Release
- **Autonomous Control Tower Explorer:** Activity Bar interface for Hath0r Autonomous Bots (Context Manager, Memory Manager, Token Telemetry, WASM Runtime, Voice Daemon, Paper Design).
- **Agent Roles & Contracts:** Interactive view of multi-agent execution hierarchies, JEV guards, and governance directives.
- **Hath0r Quality Gates & Diagnostics:** Direct integration with Hath0r Doctor, Preflight verification, and SonarCloud standards.
- **FinOps Multilingual Tokenizer Tax Inspector:** Visual metrics for subword token inflation and VRAM budgets.
- **Interactive Architecture Webview:** Real-time visual control tower canvas with Mermaid.js.
