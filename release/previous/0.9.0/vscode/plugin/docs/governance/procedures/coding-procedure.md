# Coding Procedure

**Reference:** [Coding Strategy](../strategies/coding-strategy.md) | [Coding Playbook](../playbooks/playbook-coding.md)

## Steps
1. **Design:** Review requirements and plan SOA implementation (Dependency Injection, Service Boundaries).
2. **Setup:** Initialize state variables using Safe wrappers (`Safe String`, `Safe Number`, `Safe Array`).
3. **Implement:** Write business logic utilizing the [Coding Runbook](../runbooks/coding-runbook.md) guidelines for ASync and Immutability.
4. **Test:** Validate through automated unit tests.
5. **Review:** Ensure code passes the SonarCloud Quality Gate and meets the [Coding Checklist](../checklists/coding-checklist.md).
