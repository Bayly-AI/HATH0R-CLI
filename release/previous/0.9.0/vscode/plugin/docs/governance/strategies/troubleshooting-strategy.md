# Troubleshooting Strategy

**Goal:** Provide a systematic approach to identifying and resolving bugs across multi-part applications.

## Context Chain
- **Playbook:** [Troubleshooting Playbook](../playbooks/playbook-troubleshooting.md)
- **Procedure:** [Troubleshooting Procedure](../procedures/troubleshooting-procedure.md)
- **Runbook:** [Troubleshooting Runbook](../runbooks/troubleshooting-runbook.md)
- **Checklist:** [Troubleshooting Checklist](../checklists/troubleshooting-checklist.md)

**Strategy Summary:**
We address bugs by isolating state, separating architectural concerns, tracing logs systematically, and verifying fixes thoroughly through standard CI/CD promotion paths before they ever touch production.
