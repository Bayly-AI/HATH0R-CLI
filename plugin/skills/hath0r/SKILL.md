# HATH0R Operator Skill

Use this skill when interacting with the Hath0r agentic framework, running multi-repository hygiene checks, or performing Taguchi parameter optimization and FinOps auditing.

## Common Operations

### 1. Suite Diagnostics
```bash
hath0r doctor
```

### 2. Taguchi Robust Parameter Optimization
```bash
hath0r optimize taguchi --array L9 -f temperature -f top_p --snr 120,115,118
```

### 3. FinOps Multilingual Tokenizer Tax Audit
```bash
hath0r finops tokenizer-tax "Sample prompt or file path"
```

### 4. Pixel-Native 2D Document Parsing
```bash
hath0r vision parse-doc invoice.png --pixel-native
```

### 5. Playwright Visual Grounding
```bash
hath0r vision ground screenshot.png --target "Submit Form" --playwright
```
